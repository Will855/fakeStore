# E-Commerce FakeStore API

Aplicación de React con Redux y FakeStore API para crear un E-commerce.

## Características
- Listado dinámico de productos desde una API.
- Carrito de compras funcional (agregar, eliminar, totalizar).
- Integración de estado global con Redux.
- Interfaz moderna y completamente responsive.

## Tecnologías
- React.js
- Redux / Redux Toolkit
- FakeStore API
- CSS / UI Components
